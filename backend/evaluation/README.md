# RepoMind Retrieval Evaluation & Benchmark Suite

This directory contains the reproducible retrieval evaluation suite for RepoMind, testing code-aware hybrid retrieval, AST symbol extraction, citation accuracy, and unanswerable question handling.

## Files

- `benchmark_ground_truth.jsonl`: Curated ground truth containing 25 verified benchmark questions across 3 repositories with pinned commit SHAs.
- `evaluate_retrieval.py`: Benchmark execution script computing Recall@5, MRR, citation accuracy, and unanswerable precision across Keyword (BM25), Semantic (dense vector), and Hybrid (RRF) modes.
- `evaluation_results.json`: Output report generated by `evaluate_retrieval.py` containing aggregated metrics and per-question retrieval traces.

## Running the Benchmark

From the `backend` directory:

```powershell
C:\Python314\python.exe evaluation/evaluate_retrieval.py
```

Expected output:
- Keyword Recall@5, MRR
- Semantic Recall@5, MRR
- Hybrid Recall@5, MRR
- Citation Accuracy (1-indexed lines and source file existence)
- Unanswerable Precision (refusal on out-of-scope concepts)

## Optional CodeSearchNet Extension

CodeSearchNet (Husain et al.) is a standard dataset for code retrieval containing ~2M (comment, code) pairs across Python, JavaScript, Go, PHP, Java, and Ruby.

### Why It Is Kept Optional & Separate
1. **Size & Overhead**: CodeSearchNet is several gigabytes in size. Downloading or embedding it during application startup would severely degrade startup latency and exceed lightweight local disk constraints.
2. **Granularity**: CodeSearchNet evaluates snippet-level text-to-code matching, whereas RepoMind focuses on repository-level AST call graphs, cross-file import tracing, and line-level citation groundedness.

### Architecture for Future CodeSearchNet Integration

To evaluate RepoMind on CodeSearchNet without impacting production code:

1. **Standalone Download Script**:
   Create `evaluation/download_codesearchnet.py` using Hugging Face datasets:
   ```python
   # evaluation/download_codesearchnet.py
   from datasets import load_dataset
   # Stream or download subset
   dataset = load_dataset("code_search_net", "python", split="test", streaming=True)
   ```

2. **Format Conversion**:
   Convert samples into RepoMind's benchmark format:
   ```json
   {
     "id": "csn_py_0001",
     "category": "natural_language_search",
     "repo_id": "csn-benchmark-repo",
     "question": "function docstring / natural language query",
     "expected_files": ["module.py"],
     "expected_symbols": ["target_function"]
   }
   ```

3. **Isolated Ingestion**:
   Index the benchmark snippets into an ephemeral collection in Qdrant (e.g. `codesearchnet_benchmark`) and run `evaluate_retrieval.py --dataset evaluation/codesearchnet_subset.jsonl`.
